# Heart Disease Prediction

## Overview
This project uses Machine Learning to predict whether a person is likely
to have heart disease based on various medical and demographic features.

## Dataset
The dataset contains information such as:
- Age
- Sex
- Chest pain type
- Resting blood pressure
- Cholesterol
- Maximum heart rate
- Exercise-induced angina
- Other relevant features

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning
The project includes:
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature selection
- Train-test split
- Feature scaling
- Model training
- Model evaluation

## Model Evaluation
The model is evaluated using metrics such as:
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
